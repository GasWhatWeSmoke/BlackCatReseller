# Reporting security issues

Use GitHub's **Security > Report a vulnerability** option to send a private report
to the maintainer. Include the affected version, reproduction steps, and impact.
Use synthetic data and avoid sending account passwords, tokens, cookies, or customer
information.

Please keep vulnerability details out of public issues until the maintainer has
had an opportunity to investigate and prepare a fix. Regular bugs and feature
requests belong in the public issue tracker.

Black Cat Reseller is currently a beta. Security fixes target the current source
and the next release.
