## Installation and workspace

- [ ] Install/extract in a writable folder using a standard Windows account.
- [ ] Open from the supplied executable/shortcut without developer tools.
- [ ] Finish worker setup and record any error and its local log location.
- [ ] Reopen Getting started from Settings and inspect the saved folder paths.
- [ ] Keep camera originals separately; verify available space and backup status.
- [ ] Leave Auto Run off. Start with AI off unless optional runtime status is ready.
- [ ] For browser work, connect Chrome, a second monitor and the intended accounts.
      Complete browser approval/sign-in personally; never share credentials.

## Intake, review and persistence

Choose ten garments with varied labels/colors/types and unused SKUs. Photograph
at least three views per garment and its own SKU marker last. Export JPEGs in
capture order. Record independently what each garment and tag actually show.

Starter labels are supplied as **BETA-TEN-LABELS.html**, and the in-app tutorial
links to `/beta-labels.html`. Open the saved HTML in a browser, press **Ctrl+P**
and print at 100% scale. Keep the white QR borders when cutting. These labels
encode **BC-000001–BC-000010**: use them only with a new empty inventory or when
all ten numbers are confirmed unused. Use different labels for existing SKUs.

- [ ] Upload one complete folder. Confirm exactly ten garment groups.
- [ ] Match every group to the garment, including all its photographs.
- [ ] Check that marker images are excluded from listing photos.
- [ ] Repair missing-marker/wrong-group cases explicitly and check again.
- [ ] Review each item individually; record incorrect or missing suggestions.
- [ ] Check category, department, platform-specific size, color, condition, brand,
      price, shipping weight, measurements and every factual claim in the copy.
- [ ] Approve reviewed items; inspect their prepared photos and listing copy.
- [ ] Quit through the tray, reopen and verify all ten items, edits and photos.
- [ ] Verify a completed backup exists. A restore drill must use an isolated copy,
      never overwrite the tester's live data to test restoration.

## Optional real marketplace test

Select actual stock intended for sale. The local intake test can be complete while
this section remains **not tested**. A successful internal response alone does
not count as a verified live listing.

- [ ] Choose the exact items/platforms in Crosslisting and check the confirmation.
- [ ] Verify each actual marketplace URL and exact garment identity.
- [ ] Verify photos, price, category, department, size and color on each platform.
- [ ] Inspect failed/uncertain outcomes before retrying; avoid duplicate listings.
- [ ] When a legitimate sale occurs, check its exact-item match, fulfillment and
      removal of known counterpart listings. Do not invent a sale to tick this box.
